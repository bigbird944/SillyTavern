# tavern-cards 与 tavern_helper_template 冲突检查报告

检查时间：2026-06-17 15:45

## 工具概况

### 1. tavern-cards (Kilo Skill)
- **位置**：`.kilo/skill/tavern-cards/`
- **功能**：角色卡和世界书内容创作工具
- **CLI 工具**：`.kilo/skill/tavern-cards/scripts/tavern-cards-forge.mjs`
- **工作目录**：项目根目录下的 `cards/{ProjectName}/`
- **配置文件**：`.cardrc.json`（需要从模板复制）

### 2. tavern_helper_template (前端开发工具)
- **位置**：`tavern_helper_template/`
- **功能**：MVU 状态栏前端界面开发
- **工作目录**：`tavern_helper_template/src/{ProjectName}/界面/状态栏/`
- **输出目录**：`tavern_helper_template/dist/`
- **配置文件**：`tavern_helper_template/package.json`

## 冲突分析结果

### ✅ 无路径冲突
1. **工作目录完全分离**：
   - tavern-cards 在 `cards/` 目录工作
   - tavern_helper_template 在 `tavern_helper_template/` 目录工作
   - 两者不会互相覆盖文件

2. **配置文件独立**：
   - tavern-cards 使用 `.cardrc.json`
   - tavern_helper_template 使用 `package.json`
   - 无配置冲突

3. **CLI 工具独立**：
   - tavern-cards: `node .kilo/skill/tavern-cards/scripts/tavern-cards-forge.mjs`
   - tavern_helper_template: `pnpm watch` / `pnpm build`
   - 命令空间不冲突

### ✅ 协作流程清晰

工作流程是串行的，不是并行的：

```
1. 使用 tavern-cards 创作角色卡内容
   ├── 编写 schema.ts（MVU 变量结构）
   ├── 编写条目内容
   └── 生成 cards/{Project}/

2. 使用 tavern_helper_template 开发状态栏（可选）
   ├── 复制 schema.ts 到 tavern_helper_template/src/{Project}/
   ├── 在 tavern_helper_template 中开发界面
   ├── 构建输出到 tavern_helper_template/dist/
   └── 部署到 CDN

3. 回到 tavern-cards 更新占位符
   ├── 修改 cards/{Project}/正则/状态栏界面.html
   └── 重新打包角色卡
```

### ⚠️ 需要注意的配置点

#### 1. schema.ts 文件需要手动同步
- **位置 1**：`cards/{ProjectName}/schema.ts`（tavern-cards 项目）
- **位置 2**：`tavern_helper_template/src/{ProjectName}/schema.ts`（前端项目）
- **注意**：两个文件结构互通但需手动复制保持同步

#### 2. 路径引用规范
tavern-cards 文档中的路径示例使用 Unix 风格：
```bash
cp /path/to/project/schema.ts src/{ProjectName}/schema.ts
```

Windows 环境下应使用：
```powershell
Copy-Item -Path "cards\{ProjectName}\schema.ts" -Destination "tavern_helper_template\src\{ProjectName}\schema.ts"
```

#### 3. CLI 工具调用路径
tavern-cards CLI 工具的完整路径：
```bash
node .kilo/skill/tavern-cards/scripts/tavern-cards-forge.mjs <command> <args>
```

由于工具在 `.kilo/skill/` 下，建议在项目根目录执行。

### ✅ 环境依赖独立

1. **tavern-cards**：
   - 依赖：Node.js
   - 无 node_modules（CLI 工具已打包）

2. **tavern_helper_template**：
   - 依赖：Node.js + pnpm
   - 已安装 861 个包到 `tavern_helper_template/node_modules/`
   - 不影响其他目录

## 缺失配置

### 需要创建的文件

1. **`.cardrc.json`**（必需）
   - 当前状态：不存在
   - 操作：复制 `.kilo/skill/tavern-cards/assets/cardrc.json` 到项目根目录为 `.cardrc.json`
   - 用途：tavern-cards-forge CLI 工具的项目注册配置

2. **`cards/` 目录**（使用时创建）
   - 当前状态：不存在
   - 操作：运行 `node .kilo/skill/tavern-cards/scripts/tavern-cards-forge.mjs init {project}` 自动创建
   - 用途：存放角色卡项目

## 总结

### ✅ 无冲突
- 目录结构完全独立
- 配置文件不冲突
- CLI 命令空间分离
- 依赖环境隔离

### ✅ 可以安全使用
两个工具可以在同一项目中共存，按照以下原则使用：
1. tavern-cards 负责内容创作（文本、逻辑、配置）
2. tavern_helper_template 负责前端开发（可视化界面）
3. 通过 schema.ts 手动同步变量结构
4. 最终产物互相引用（状态栏 URL → 角色卡）

### ⚠️ 需要初始化
在开始使用前，需要：
1. 复制 `.cardrc.json` 配置文件到根目录
2. 根据项目需求决定是否使用 tavern_helper_template

### 📝 建议
- 将 CLI 工具路径添加到 PATH 或创建快捷脚本
- 使用版本控制时，排除 `tavern_helper_template/node_modules/` 和 `tavern_helper_template/dist/`
